# SheetToTxt — setup

Excel VSTO add-in. Adds a **Home ▸ Sheet to TXT ▸ Export Sheet to .txt** button that
writes the active worksheet to `<WorkbookName>.txt` in the workbook's own folder, using
Excel's "Text (Tab delimited)" format.

## One-time prerequisite (required before the project will build)

The Visual Studio **"Office/SharePoint development"** workload is **not installed** on this
machine. Nothing builds without it. Install via **one** of:

- Visual Studio Installer ▸ *Modify* ▸ check **Office/SharePoint development** ▸ *Modify*.
- Elevated shell:
  ```
  "C:\Program Files (x86)\Microsoft Visual Studio\Installer\setup.exe" modify ^
    --installPath "C:\Program Files\Microsoft Visual Studio\2022\Community" ^
    --add Microsoft.VisualStudio.Workload.Office --includeRecommended --passive
  ```

That installs `Microsoft.VisualStudio.Tools.Office.targets`, the VSTO project templates,
and the design-time assemblies the checked-in files reference.

## Build & run

1. Open `..\PDGO365Addins.sln` in Visual Studio 2022.
2. Press **F5**. VS builds, registers the add-in under
   `HKCU\Software\Microsoft\Office\Excel\Addins\SheetToTxt`, launches Excel, and attaches
   the debugger.
3. Open/save any `.xlsx`, click **Home ▸ Export Sheet to .txt**. A `.txt` with the same
   base name appears next to the workbook.

Command-line build (after the workload is installed):
```
"C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" ^
  ..\PDGO365Addins.sln /p:Configuration=Debug
```

## If Visual Studio rejects the hand-written project files

These files were authored without the VSTO templates installed, so the project system
*may* complain about `SheetToTxt.csproj`, `ThisAddIn.Designer.cs`, or
`ThisAddIn.Designer.xml` on first load. If that happens:

1. `File ▸ New ▸ Project ▸ "Excel VSTO Add-in"`, name it `SheetToTxt`, .NET Framework 4.8.
2. Delete the template's placeholder `ThisAddIn.cs` body content and replace with the
   version in this folder.
3. Add the checked-in `SheetExporter.cs`, `WorkbookLocation.cs`, and `Ribbon\` folder to
   the project (they are template-independent — the real logic lives there).
4. In `ThisAddIn.cs`, keep the `CreateRibbonExtensibilityObject` override that returns
   `new Ribbon.SheetToTxtRibbon()`.
5. Mark `Ribbon\SheetToTxtRibbon.xml` as **Embedded Resource**.

## Files

| File | Role |
| --- | --- |
| `ThisAddIn.cs` | Startup/shutdown; registers the XML ribbon. Hand-written. |
| `ThisAddIn.Designer.cs` / `.xml` | VSTO plumbing. Regenerated by the VSTO designer on build. |
| `Ribbon/SheetToTxtRibbon.xml` | Ribbon markup (Home tab button). Embedded resource. |
| `Ribbon/SheetToTxtRibbon.cs` | `IRibbonExtensibility` — thin callbacks. |
| `SheetExporter.cs` | Core logic: copy active sheet → `Workbook.SaveAs(..xlTextWindows)`. |
| `WorkbookLocation.cs` | Resolves the workbook folder + base name for the output path. |

## Notes on behavior

- The workbook must be **saved to a real folder** first (a never-saved workbook, or a
  cloud-only file with a URL path, is rejected with a clear message).
- An existing `.txt` of the same name is **overwritten** silently.
- Export uses ANSI (system code page). For sheets with characters outside that code page,
  change `TextFormat` in `SheetExporter.cs` to `Excel.XlFileFormat.xlUnicodeText`.
