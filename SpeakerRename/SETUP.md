# SpeakerRename — setup

Word VSTO add-in. Adds a **Home ▸ Speaker Rename ▸ Rename Speakers** button that:

1. Scans the active document for every `Speaker N` label — body, tables, headers/footers
   (every section), footnotes/endnotes, comments, and text boxes (including text boxes
   inside headers/footers).
2. Opens a dialog that walks through each **unique speaker number** one at a time
   (Back / Next, or click any speaker in the list), ordered `Speaker 1, 2, 3…`. Each
   speaker shows how often their label appears and a snippet of surrounding text.
3. On **Finish** / **Rename All**, replaces every occurrence of each named speaker's
   label with the entered name. Speakers left blank are not touched. The whole rename is
   **one Undo step** (Ctrl+Z once reverts it).

## What counts as a speaker label

- `Speaker` + one or more spaces/tabs + one or more digits, e.g. `Speaker 1`, `Speaker 12`.
  `Speaker1` (no space) and `Speaker 10a` are not matched.
- Grouping is by **number**, not exact text: `Speaker 3` appearing with different amounts
  of internal whitespace is still one speaker, and every distinct variant found gets
  replaced.
- Matching the word `Speaker` itself is **case-sensitive**, the same policy as
  BracketFields: `Speaker 1` and `speaker 1` would be treated as different labels if the
  latter ever appeared. Real transcripts render this label consistently, so this is not
  expected to matter in practice.
- Tokens longer than 255 characters are ignored (Word's Find limit; not a realistic case
  for this label).
- The replacement takes the formatting of the label it replaces.

## Build & run

Prerequisites are the same as every add-in in this repo — Office workload installed and
the shared PDG Code Signing `.pfx` imported into `CurrentUser\My`. See
`..\SheetToTxt\SETUP.md` ("Signing certificate") and `..\CLAUDE.md` §2–3.

1. Open `..\PDGO365Addins.sln` in Visual Studio 2022, set **SpeakerRename** as the startup
   project, press **F5**. VS builds, registers the add-in under
   `HKCU\Software\Microsoft\Office\Word\Addins\SpeakerRename`, and launches Word.
2. Open a transcript document with `Speaker 1`, `Speaker 2`, … labels and click
   **Home ▸ Rename Speakers**.

Command line:
```
"C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" ^
  SpeakerRename.csproj /p:Configuration=Debug
```
A plain build already registers the add-in for the current user; `/t:Clean` unregisters it.

## Files

| File | Role |
| --- | --- |
| `ThisAddIn.cs` | Startup/shutdown; registers the XML ribbon; re-evaluates the button on `DocumentChange`. |
| `ThisAddIn.Designer.cs` / `.xml` | VSTO plumbing (Word host). Regenerated by the VSTO designer. |
| `Ribbon/SpeakerRenameRibbon.xml` | Ribbon markup (Home tab button). Embedded resource. |
| `Ribbon/SpeakerRenameRibbon.cs` | `IRibbonExtensibility` — thin callbacks: scan → dialog → replace → summary. |
| `DocumentStories.cs` | Enumerates every text story (incl. header/footer shapes). Shared by scan and replace. |
| `SpeakerFieldScanner.cs` | Regex over each story's text → unique speaker numbers, ordered `1, 2, 3…`. |
| `SpeakerFieldReplacer.cs` | Find loop per story per label variant, sets `Range.Text`, wrapped in one `UndoRecord`. |
| `SpeakerField.cs` | Model: speaker number, label-text variants, occurrences, context snippet, entered name. |
| `UI/RenameSpeakersForm.cs` | The walkthrough dialog (built in code, no designer file). |

## Known limits

- A label split across a Word field code / content-control boundary may be counted by the
  scan but not replaced (the summary's occurrence count will then be lower than expected).
- With **Track Changes on**, replacements are tracked as normal revisions, and text inside
  a *deleted* revision is still scanned.
- A protected document (Restrict Editing) is refused with a message; unprotect it first.

## Deployment

Same model as SheetToTxt/BracketFields — see `..\deploy\README.md`. Publish with
`deploy\Publish-SpeakerRename.ps1 -Version 1.0.1.0` into
`…\SOFTWARE RESOURCES\O365\SpeakerRename`; the team runs `Install-SpeakerRename.ps1` from
their synced copy (guide: `deploy\INSTALL-SpeakerRename.md`, published as `INSTALL.md`).
